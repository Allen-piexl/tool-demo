# Tool Demo

This repository contains two local demo components:

- `llm_primitives/`: FastAPI LLM-backed primitives for stock, news, Amazon, and Kiwi flight booking.
- `primitive-demo-frontend/`: Next.js frontend for chatting with primitives and running the Kiwi booking flow.

Do not commit real API keys. Copy the example env files and fill secrets locally or on the server.
